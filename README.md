## 📖 Overview

A sleek, bespoke developer portfolio engineered with **Next.js 14 (App Router)**, **React 18**, **TypeScript**, and **Vanilla CSS**. Designed with an **Obsidian Dark & Royal Blue (`#005fea`)** visual hierarchy inspired by world-class software engineer portfolios.

It showcases production work across **Cross-Platform Mobile Engineering (Flutter & Dart)** and **Modern Full-Stack Web Development (Next.js 14, React 18, TypeScript, Tailwind CSS)**, alongside cloud infrastructure with **Firebase** and **Supabase**.

---

## ✨ Key Features & Architecture

* **🎨 Unified Obsidian & Royal Blue Aesthetics:** Curated dark theme featuring glassmorphism, subtle glowing borders, and high-contrast typography.
* **🖱️ Custom Precision Cursor:** Interactive dual-layer cursor (6px dot + 32px smooth trailing glow) with tactile feedback on clicks and hover states.
* **⚡ Bento Grid Layout:** Asymmetrical bento components presenting work history at **LogicCraft Technologies**, **Arfa Karim Technology Incubator**, and academic credentials from **KUST Kohat**.
* **📱 Filterable Projects Showcase:** Categorized gallery for Mobile, Web, and Full-Stack apps with direct repository links (e.g. `Tenant_Links`, `RentMate1`).
* **📧 Interactive Contact Channel:** Integrated API route with Formspree handling, direct Gmail mailto fallback, and celebration confetti.
* **🚀 Zero Layout Shift (CLS 0) & Performance:** Fluid GSAP animations tuned with `gsap.fromTo` and `clearProps` to ensure 60fps rendering without StrictMode lockups.
* **💬 Direct WhatsApp floating action button:** Instant consultation access with custom pre-filled message triggers.

## 🚀 Getting Started Locally

### Prerequisites
- Node.js (version 18.17.0 or higher recommended)
- npm or yarn

### 1. Clone the repository
```bash
git clone https://github.com/farazmehmood99/faraz-portfolio.git
cd faraz-portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start local development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) or [http://localhost:3001](http://localhost:3001) in your browser.

### 4. Build for production
```bash
npm run build
npm run start
```
